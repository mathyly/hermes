Privacy policy

Last updated: 19 October 2026

Who uses Hermes

Hermes is a private assistant used only by its owner. No other Google accounts are invited or supported.

Data accessed

  • Gmail (read-only): message content and metadata of the owner's mailbox, used to answer the owner's questions and prepare summaries.
  • Google Calendar: events of calendars the owner can access, used to show the schedule and to create or edit events on the owner's request.

Storage and sharing

Data is processed on a server owned by the owner. It is not sold, not used for advertising, and not shared with third parties. OAuth tokens are stored only on that server.

Google API Services User Data Policy

Hermes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Use the support e-mail address shown on the Google consent screen of this app.
